# Timeline display fonts

Derived from Adobe Source Han Serif SC Heavy (思源宋体 Heavy, weight 900), under SIL Open Font License 1.1. Copyright and full terms are in [OFL.txt](OFL.txt).

Source: https://github.com/adobe-fonts/source-han-serif
Original: https://raw.githubusercontent.com/adobe-fonts/source-han-serif/release/OTF/SimplifiedChinese/SourceHanSerifSC-Heavy.otf

Glyph outlines are unchanged. These WOFF2 subsets are renamed internally to “Timeline Serif” to respect the reserved font name. The title has a small dedicated subset; player names use Unicode-range subsets so only the characters needed are downloaded. All original Unicode coverage is retained across the name subsets.
